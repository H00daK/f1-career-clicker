# 🏎️ F1 Career Clicker

Кликер-игра про карьеру гонщика: путь от картинга до Формулы 1. Сделана как **Telegram Mini App** — открывается прямо внутри Telegram через бота.

Кликай по болиду, зарабатывай монеты и опыт, прокачивай машину, побеждай в турнирах и поднимайся по карьерной лестнице: Картинг → Формула 4 → Формула 3 → Формула 2 → Формула 1.

> Fan game. Не связана с Formula 1, FIA или какой-либо командой. Используется в некоммерческих целях.

---

## 🎮 Возможности

- **Кликер-ядро** — монеты и опыт за каждый тап, пассивный доход (монеты/сек).
- **Прокачка болида** — 8 узлов (шины, двигатель, аэродинамика, подвеска, коробка, топливо, инженеры, симулятор).
- **Карьера** — 5 уровней от картинга до Ф1, переход по набору опыта, прокачке и победам.
- **Команды и пилоты** — выбор команды со своими цветами, бонусами и ливреей болида.
- **Турниры** — режимы риска (осторожно / стандарт / агрессивно), победа зависит от прокачки.
- **Сезон-чемпионат** — борьба за титул и кубки в Трофейный зал.
- **Команда (R&D)** — вложения в отделы (мотор, аэродинамика, надёжность) ради постоянных бонусов.
- **Лига** — еженедельное соревнование игроков по дивизионам (Бронза → Алмаз).
- **Контракты** — сменяемые задания с наградами.
- **Достижения** — за ключевые вехи прогресса.
- **Гараж** — бусты, косметика и ливреи, меняющие вид болида.
- **Погода** — влияет на риск и награды турниров (ясно / дождь / туман / ветер).
- **Топы** — рейтинги по победам, уровню, богатству и приглашённым друзьям.
- **Клубы** — командные объединения игроков.
- **Рефералы** — бонусы за приглашённых друзей.
- **Облачные сохранения** — прогресс синхронизируется между устройствами.

---

## 🛠️ Технологии

- Чистый **HTML + CSS + JavaScript**, без фреймворков и сборки.
- Графика болидов и все иконки — **SVG / Canvas**, рисуются кодом (без внешних картинок).
- Хранилище: **localStorage** (локально) + **Supabase** (облако, через REST).
- Хостинг: **GitHub Pages**.
- Вся игра — в одном файле `index.html`.

## 🚀 Запуск и деплой

### Локально
Просто открой `index.html` в браузере — игра работает и без Telegram (Mini App функции вне Telegram отключаются автоматически).

### На GitHub Pages
1. Залей `index.html` в репозиторий.
2. **Settings → Pages → Source: ветка `main`, папка `/root`**.
3. Сайт раздаётся по адресу `https://<username>.github.io/f1-career-clicker/`.

> **Важно:** Telegram агрессивно кэширует Mini Apps. После обновления игры может потребоваться перезапуск приложения Telegram или открытие ссылки с параметром (`?v=2`, `?v=3` …), чтобы подтянулась свежая версия.

## 🤖 Связь с ботом

Игра открывается через отдельного **Telegram-бота** (в другом репозитории). Бот показывает кнопку «Играть», передаёт данные пользователя и реферальные ссылки, а также шлёт уведомления.

| Репозиторий | Файл | Назначение |
|---|---|---|
| `f1-career-clicker` | `index.html` | сама игра (этот репозиторий) |
| `f1-career-bot` | `bot.py` | Telegram-бот (отдельный репозиторий) |

## ☁️ Облачные сохранения (Supabase)

Прогресс хранится в таблице `players`. Игра обращается к Supabase через REST с публичным ключом; запись в облако происходит только после завершения регистрации (ввода имени).

Лидерборды реализованы как представления (VIEW) поверх таблицы `players` и обновляются автоматически.

> Ключи и адрес проекта Supabase в этот репозиторий **не** коммитятся в открытом виде сверх необходимого. Секретные ключи (service_role) используются только ботом и хранятся в переменных окружения хостинга, а не в коде.

---

## ⚙️ Полезные параметры в коде

- `WIPE_VERSION` — версия принудительного сброса прогресса. Увеличь число, чтобы при следующем заходе у всех игроков локальный прогресс начался заново (используется перед крупными обновлениями/сезонами).
- Пороги перехода между уровнями карьеры и баланс наград настраиваются в массивах `CAREERS`, `UPGRADES`, `QUEST_POOL` в начале скрипта.
