# 🏎 F1 Career Clicker

> Telegram Mini App — кликер-RPG о карьере гонщика от картинга до Формулы 1

**Живая игра:** [t.me/F1CareerBot/Formula](https://t.me/F1CareerBot/Formula)  
**Хостинг:** [h00dak.github.io/f1-career-clicker](https://h00dak.github.io/f1-career-clicker/)

---

## 🎮 О игре

F1 Career Clicker — это Telegram Mini App в жанре кликер/idle с элементами RPG. Игрок начинает карьеру с картинга и проходит путь до Формулы 1, прокачивая болид, участвуя в турнирах и получая офферы от академий реальных команд сезона 2026.

**Не является официальным продуктом Formula One Group или команд F1. Fan project.**

---

## ✅ Что реализовано

### 🏗 Технический стек
- **Frontend:** один HTML файл (HTML + CSS + Canvas JS) — без фреймворков
- **Хостинг:** GitHub Pages (бесплатно)
- **База данных:** Supabase (PostgreSQL, бесплатный тир)
- **Telegram:** Mini App через BotFather, Telegram WebApp SDK

### 🎯 Геймплей
- **5 уровней карьеры:** Картинг → Формула 4 → Формула 3 → Формула 2 → Формула 1
- **Клики** — основной источник монет и XP
- **8 апгрейдов** с ростом цен: Шины, Двигатель, Аэродинамика, Подвеска, Коробка передач, Топливо, Инженеры, Симулятор
- **Пассивный доход** (м/сек) — монеты без кликов
- **Турниры** — уникальные для каждого уровня карьеры (3 турнира × 5 уровней = 15 турниров)
- **Случайный исход** турниров с шансом победы зависящим от прокачки
- **8 достижений**
- **Система офферов** от академий Red Bull / Ferrari / Mercedes (+30% XP при принятии)

### 🔒 Условия перехода на следующий уровень
1. Набрать необходимый XP
2. Прокачать болид минимум на **70%**
3. Победить в каждом доступном турнире **хотя бы раз**
- При переходе **апгрейды сбрасываются**, монеты и прогресс сохраняются

### 🏆 Лидерборд
- Хранится в Supabase
- Топ-20 игроков по количеству побед
- Видно: место, имя, команда, уровень карьеры
- Медали 🥇🥈🥉 для топ-3
- Своя строка подсвечена

### 🏎 Визуал — болиды на Canvas
Каждый уровень имеет уникальный болид нарисованный через Canvas API:
- **Картинг** — низкий открытый карт с шлемом в профиль
- **Ф4** — первый монокок, маленькое антикрыло
- **Ф3** — шире, двойная акцент-полоса, подголовник
- **Ф2** — воздухозаборники, высокое антикрыло, диффузор
- **Ф1** — HALO, сложное переднее крыло, выхлоп

Болид перекрашивается в цвета выбранной команды. На болиде — табличка с реальным номером и фамилией гонщика.

## 🔧 Технические детали

### Supabase
- **Project URL:** `https://ypdqmvivmqwhqurfpnkn.supabase.co`
- **Таблица:** `players` — хранит прогресс по Telegram User ID
- **View:** `leaderboard` — топ игроков по победам

### Схема таблицы players
```sql
id              bigint    -- Telegram User ID
name            text      -- Имя гонщика
team_id         text      -- ID команды
coins           numeric   -- Монеты
xp              numeric   -- Опыт
career_level    int       -- Уровень карьеры (0-4)
total_wins      int       -- Всего побед
upgrades        jsonb     -- Уровни апгрейдов
won_tournaments jsonb     -- Выигранные турниры
updated_at      timestamp -- Время обновления
```

### Ключи localStorage
- `f1_v6` — текущая версия сохранения
