# 🏎️ F1 Career Clicker

Кликер-игра про карьеру гонщика — от картинга до Формулы 1. Сделана как **Telegram Mini App**: открывается прямо внутри Telegram, прогресс синхронизируется в облако.

> **Играть:** [t.me/F1CareerBot/Formula](https://t.me/F1CareerBot/Formula)

Это фан-проект, не связанный с Formula One Group, командами или пилотами.

---

## 🎮 Об игре

Ты начинаешь карьеру в картинге и прокладываешь путь до Формулы 1, прокачивая болид, выигрывая турниры и сезонные чемпионаты. Чем дальше — тем дороже апгрейды и выше доход.

**Путь карьеры:** Картинг → Формула 4 → Формула 3 → Формула 2 → Формула 1

Чтобы перейти на следующий уровень, нужно набрать опыт (XP), прокачать болид минимум на 70% и выиграть все турниры текущего уровня.

---

## ✨ Возможности

**Карьера и прогресс**
- 5 уровней карьеры с растущей сложностью и доходом
- 8 типов апгрейдов болида, цены и отдача масштабируются с уровнем
- При переходе на новый уровень часть наработанного дохода переносится как стартовая фора — труд не обнуляется
- Система престижа: начни заново ради постоянного множителя дохода (Очки наследия)

**Команды и пилоты**
- 11 команд сезона 2026 (включая Audi и Cadillac) с уникальными цветами и бонусами
- Выбор из двух реальных пилотов в каждой команде, с индивидуальной расцветкой шлема и флагом национальности
- Болид нарисован на Canvas и перекрашивается в цвета команды; детали болида меняются по мере прокачки
- Болид едет тем быстрее, чем быстрее ты кликаешь

**Соревнования**
- Турниры с режимами риска (осторожный / стандартный / агрессивный)
- Сезонный чемпионат против именных соперников с борьбой за титул
- Заезды на время: 30 секунд кликов, средний темп определяет место в таблице рекордов
- Лидерборды по победам, уровню, богатству и рефералам
- Трофейный зал — кубки за чемпионства на каждом уровне

**Активности и удержание**
- Ежедневный бонус со стриком-множителем
- Спонсорские контракты (квесты) с наградами
- Гараж: постоянные улучшения, косметика и временные бусты
- Оффлайн-доход за время отсутствия
- Реферальная система с наградой, масштабируемой по уровню

**Прочее**
- Звук и тактильная отдача (haptics)
- Профиль с титулами, статистикой и аватаром-шлемом
- Туториал для новичков
- Учёт времени в игре
- Админ-панель для управления (только для заданных Telegram ID)

## 🛠️ Технологии

- **Frontend:** чистый HTML / CSS / JavaScript, без фреймворков
- **Графика:** HTML5 Canvas (болиды, шлемы, флаги, анимация движения рисуются кодом)
- **Платформа:** Telegram Mini App (Telegram WebApp API)
- **Бэкенд:** [Supabase](https://supabase.com) (PostgreSQL) для облачных сейвов и лидербордов
- **Хостинг:** GitHub Pages
- **Зависимости:** нет — вся игра в одном файле `index.html`

## 🚀 Запуск

### Локально
Открой `index.html` в браузере. Вне Telegram часть функций (облачный сейв, рефералы) работает в ограниченном режиме, но геймплей доступен.

### Деплой как Telegram Mini App
1. Залей `index.html` на любой статический хостинг (GitHub Pages, Netlify, Vercel).
2. Создай бота через [@BotFather](https://t.me/BotFather).
3. Привяжи URL игры к боту через `/newapp` (Mini App).
4. Настрой базу Supabase (см. ниже).

### База данных (Supabase)
1. Создай проект на [supabase.com](https://supabase.com).
2. Создай таблицу `players` и примени миграции:
   - `race-migration.sql` — добавляет колонку рекордов заездов.
3. Впиши свои `SB_URL` и `SB_KEY` в начале скрипта в `index.html`.

### Админ-доступ
В `index.html` найди строку `const ADMIN_IDS=[...]` и впиши numeric Telegram ID администраторов (узнать свой ID можно у бота [@userinfobot](https://t.me/userinfobot)). Первый в списке — главный админ.

### Push-уведомления (опционально)
`push-bot.js` — серверный скрипт для напоминаний неактивным игрокам. Требует Node 18+, запускается по расписанию (cron) на сервере с доступом к секретам (Replit, Railway, Supabase Edge Functions). На GitHub Pages не работает.
