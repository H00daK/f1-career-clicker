🏎️ F1 Career Clicker
Кликер-игра про карьеру гонщика — пройди путь от картинга до Формулы 1. Сделана как Telegram Mini App: открывается прямо внутри Telegram, прогресс синхронизируется между устройствами через облако.
🎮 Играть: t.me/F1CareerBot/Formula

Об игре
Ты начинаешь карьеру за рулём карта и постепенно поднимаешься по гоночной лестнице: Картинг → Формула 4 → Формула 3 → Формула 2 → Формула 1. На каждом этапе прокачиваешь болид, выигрываешь турниры, проходишь чемпионаты сезона и зарабатываешь на переход в следующую категорию. На вершине — система престижа: начни заново как легенда и получи постоянные бонусы.
Возможности

5 уровней карьеры — от картинга до Ф1, с растущими по размеру и детализации болидами (визуальная награда за продвижение).
8 узлов прокачки болида — шины, двигатель, аэродинамика, подвеска, коробка передач, топливо, инженеры, симулятор. Каждый улучшает доход с клика и пассивный заработок.
Турниры — 15 турниров (по 3 на уровень) с риском и наградой: шанс победы зависит от прокачки болида. На голом болиде играть невыгодно, на прокачанном — приносит прибыль.
Чемпионат сезона — 10 Гран-при против соперников, борьба за титул и кубок в Трофейный зал.
Спонсорские контракты (квесты) — задания на клики, победы, заработок и прокачку с денежными наградами.
R&D — развитие команды — три направления (двигатель / аэродинамика / надёжность), усиливающие доход и шансы. Сбрасываются при престиже.
11 команд сезона 2026 — включая Audi и Cadillac, у каждой свои бонусы (доход, XP, цена апгрейдов, шанс) и реальные пилоты с индивидуальными цветами шлемов и флагами 15 национальностей.
Гараж и ливреи — косметические покрытия болида (полоса, карбон, золото).
Заезд на скорость — мини-игра на скорость клика с глобальным рейтингом.
Клубы — объединяйся с другими игроками, общий рейтинг клубов.
Достижения — 15 наград за разные этапы пути.
Престиж — перезапуск карьеры за Очки наследия, дающие постоянный бонус к доходу. Косметика, достижения и трофеи сохраняются.
Оффлайн-доход, ежедневный бонус со стриком, реферальная система.
Облачная синхронизация — прогресс хранится в облаке и доступен с любого устройства, где открыт Telegram.

Технологии

Чистый HTML / CSS / JavaScript — без фреймворков. Вся игра в одном файле index.html.
Canvas 2D — все болиды, шлемы, флаги и аватары отрисованы кодом (никаких внешних картинок).
Telegram Mini Apps API — запуск и идентификация пользователя внутри Telegram.
localStorage — локальное сохранение прогресса.
Supabase (PostgreSQL + REST) — облачные сохранения, рейтинги, клубы.
GitHub Pages — хостинг.

Запуск локально
Игра — это один статический файл, сборка не нужна.
bash# клонировать репозиторий
git clone https://github.com/H00daK/f1-career-clicker.git
cd f1-career-clicker

# открыть index.html в браузере любым удобным способом, например:
python3 -m http.server 8000
# затем открой http://localhost:8000

Облачные функции (синхронизация, рейтинги, клубы) и интеграция с Telegram работают только при запуске как Mini App внутри Telegram и при настроенном Supabase. В обычном браузере игра запускается локально с сохранением в localStorage.

Деплой

Залей index.html в репозиторий.
Включи GitHub Pages (Settings → Pages → ветка main).
В @BotFather укажи URL страницы как Web App для своего бота.
